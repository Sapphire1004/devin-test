# 우리 동네 스탬프 랠리 — Astra

`1bd789b2ea367970a25fbfbc144094303d4ef5fa`의 `PLAN.md`를 기준으로 만든 독립 구현입니다.
담당 구현 이름은 Astra이며, 작업 어시스턴트는 Cognition의 Devin입니다. 경로 이름을 실제 기반 모델 식별자로 간주하지 않습니다.

## 실행

```sh
nvm install
nvm use
npm install
npm run dev
```

- Node **24.19.0**, npm **10.8.3**
- Vite **6.4.3**, React / React DOM **18.3.1**, TypeScript **5.0.4**
- QR: `@zxing/browser` **0.1.5**, `@zxing/library` **0.21.3**
- i18n: `i18next` **23.16.8**, `react-i18next` **15.1.2**
- 테스트: Vitest **4.1.11**, Testing Library React **16.3.0**, jsdom **26.1.0**
- ESLint **8.57.1**, TypeScript ESLint **8.46.2**
- 직접 의존성은 정확한 버전으로 고정하며 전체 트리는 `package-lock.json`으로 고정합니다.

서버는 `0.0.0.0:3000`에서 실행합니다. Astra 진입점은 `/astra`이며 직접 접속과 새로고침을 지원합니다.
루트 `/`에는 비교 링크만 있습니다. `/claude`는 미구현 안내이며 다른 모델의 코드는 포함하지 않습니다.
사용자 프리뷰는 Devin의 **Open preview**를 이용합니다.

## 사용

1. 다섯 장소를 확인하고 **참여하기**로 카드를 발급받습니다.
2. **QR 스캔하기**에서 카메라를 켜거나 **이미지 업로드**를 선택합니다.
3. 행사 QR 전체 문자열이 정확히 일치할 때만 스탬프를 추가합니다. 앞뒤 공백도 허용하지 않습니다.
4. 이미 방문한 장소는 최초 방문 시각을 유지합니다. 다섯 장소를 모으면 완주가 표시됩니다.
5. 재접속 시 같은 브라우저의 참여·스탬프 기록을 복원합니다.
6. **기록 초기화 → 초기화하기**로 Astra 기록을 지웁니다. 취소와 Escape도 지원합니다.

카메라는 HTTPS 또는 localhost와 브라우저 권한이 필요합니다. 권한 거부, 장치 없음, 판독 실패 시 이미지 업로드로 전환할 수 있습니다.
실제 촬영 영상이나 업로드 파일은 네트워크로 전송하지 않습니다.
스캐너 닫기, 입력 방식 전환, 탭 숨김, 페이지 이탈 시 카메라를 해제하며 늦게 도착한 권한 승인도 정리합니다.

## 한국어 / 日本語

헤더의 언어 선택에서 **한국어**와 **日本語**를 전환합니다. 처음에는 한국어로 시작하고, 선택한 언어는 `stamprally:astra:language:v1`에 저장되어 새로고침 후에도 유지됩니다. 저장소가 차단되어도 현재 화면에서는 전환할 수 있습니다.

화면 문구, 장소 이름, 스캐너·오류·초기화 안내, 접근성 이름과 방문 시각 표시를 현지화합니다. 언어를 바꿔도 참여 상태·스탬프 수·최초 방문 시각과 QR payload는 유지됩니다. 기록 초기화는 언어 설정을 지우지 않습니다.

번역은 `src/astra/locales/ko.ts`와 `ja.ts`에서 관리합니다. 일본어 리소스는 한국어와 같은 키를 갖도록 타입으로 검사합니다. Astra 전용 i18next 인스턴스를 사용하며, 다른 구현의 i18n 인스턴스나 저장 키를 사용하지 않습니다.

## 격리 및 저장

- 구현과 테스트: `src/astra/`
- 스타일: CSS Modules, Astra 최상위 컨테이너에 한정한 기본 스타일
- 저장 키: `stamprally:astra:v1`
- 저장소가 차단되거나 용량이 부족하면 안내하고 메모리에서 진행합니다. 이 경우 새 기록은 새로고침 후 사라질 수 있습니다.
- 잘못된 저장 데이터는 안내 후 새 참여를 허용합니다. 초기화 저장소 작업이 실패하면 현재 카드는 보존합니다.
- 서버, 로그인, 실제 방문 증명은 없는 브라우저 로컬 검증용 앱입니다.
- 여러 탭에서 같은 카드를 동시에 수정하는 동기화는 지원하지 않습니다. 한 탭에서 사용하세요.

## 검증

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm audit
```

테스트는 정확한 QR 검사, 중복·완주, 저장 복원·격리·실패 처리, 참여·이미지 등록·초기화 UI, 카메라 권한 경합·자원 정리, 실제 PNG 픽셀 QR 판독을 검사합니다.
컴포넌트 테스트의 카메라와 파일 브라우저 API는 모킹합니다. 실제 PNG 테스트는 ZXing 코어로 이미지 픽셀을 판독합니다.
실물 카메라 촬영 및 실제 브라우저 영상 판독 검증과는 구분해야 합니다.

### QR 테스트 이미지

`fixtures/qr/spot-1.png`부터 `spot-5.png`까지 공통 계획의 다섯 장소 QR을 담습니다.
잘못된 QR, 미등록 장소, 다른 행사, 추가 공백 이미지도 포함합니다.

```sh
npm run qr:fixtures
```

이는 QR 픽스처 생성 명령이며 문자열이나 개발용 버튼으로 스탬프를 직접 추가하는 기능은 앱에 없습니다.
